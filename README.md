# The Moon Finally Answers Back

After four billion years of wishes, howls and late-night promises, the Moon finally replies — dry, unbothered, and a little hurt that nobody ever wished it anything back. This entry is a single 168-character comeback in the Moon's own voice, written to land in one read against the house judge's head-to-head comedy brief.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
